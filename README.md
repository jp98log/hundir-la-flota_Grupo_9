# Hundir la Flota · The Bridge (Sprint 03) - hundir-la-flota_Grupo_9

Juego clásico de estrategia naval desarrollado en Python para consola.

## 📁 Estructura del Proyecto
- `variables.py`: Constantes globales y símbolos del juego.
- `clases.py`: Lógica de la clase Tablero.
- `funciones.py`: Validaciones de coordenadas y turnos.
- `main.py`: Archivo principal que ejecuta la partida.

## 🚀 Cómo Ejecutar el Juego
1. Clona el repositorio e instala las dependencias:
   ```bash
   pip install -r requirements.txt
2. Ejecuta el juego:

   python main.py

## 🔍 Leyenda de Símbolos
- `~` : Agua / Casilla vacía
- `O` : Barco
- `X` : Tocado
- `·` : Agua disparada
